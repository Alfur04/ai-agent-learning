# 真实用户问题收集

> **目标**：收集 100 条真实的年轻人财务困惑提问。
> **来源**：知乎、小红书、豆瓣小组、微博、贴吧、身边朋友。
> **搜索关键词**：负债、还不起、以贷养贷、花呗分期、信用卡最低还款、助学贷款、月光、存不下钱、该不该借钱
> **用途**：旗舰项目「智者」的 golden set 素材、需求分析依据、面试时展示用户洞察。

---

## 记录格式

每条按下面的格式追加，编号连续。**原文尽量复制，不要自己润色**——真实语气本身就是素材。

```
### 001
- 来源：（平台 + 大致时间，如：知乎 2026-10）
- 原文：「……」
- 场景分类：负债 / 储蓄 / 投资 / 社保公积金 / 大额决策
- 我的观察：（用户真正的困惑是什么？他其实在怕什么？）
```
